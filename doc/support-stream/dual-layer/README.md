# Dual layer — Superseded historical alternative

## 目录职责

- **holds**：本目录仅保存双层 Signal/Stream 方案被比较、否决和取代的历史理由，供决策追溯。
- **excludes**：不保存当前规范性目标设计；目标态归入 `../unified-graph/` 与 `doc/architect/`。
- **tier**：`stable`
- **promotes_from**：统一图决策前的方案探索、比较记录与 track 分析。
- **promotes_to**：仅晋升为决策历史或复盘材料，不投影为当前实现/API。

This document family described separate Signal and Stream runtimes. It is superseded by the accepted [Unified DataGraph target](../unified-graph/), which has no `StreamGraph` or bridge layer. Do not use it for new design or implementation work.
